# Video style library

Choose a style by name in chat, for example: **“Edit this Yap video in Editorial Tech style.”** The agent reads this index and the chosen STYLE.md, then applies it to the complete script-led plan. These are creative profiles Claude applies, not an implemented engine CLI flag or a one-click renderer.

| Style | Use | Status |
|---|---|---|
| [Yap Depth](yap-depth/STYLE.md) | Persistent title; original presenter framing; large overlays behind the head | Rendered in AI Leverage V10 |
| [Oren Static Hooks](oren-static-hooks/STYLE.md) | Immediate product/object hooks; static assets behind original presenter; frequent visual changes | User screenshot reference; planned |
| [Editorial Tech](editorial-tech/STYLE.md) | Editorial punch-ins; brief italic hook title; dark full-screen explanatory animation; real demo inserts | Reference analyzed; first custom implementation pending |

A style controls typography, composition modes, camera movement, motion, transitions and sound direction. The Yap recipe still owns script coverage, content preservation, trimming, speed and cover delivery. Preserve accepted audio/cuts when changing only visual style. State the selected profile and its meaningful differences before the plan; do not combine incompatible defaults silently.

Profiles remain optional. Selecting Editorial Tech permits planned zooms and full-screen cutaways, overriding Yap Depth's fixed framing and behind-head-only approach for that edit. Captions and sound-effects choices must be stated explicitly in the plan; a reference containing them is not permission to add them silently to unrelated edits. Existing safe zones still apply; adapt reference typography that sits outside them.

For another reference, save a new style folder with its source URL, evidence notes, observed techniques, recommended parameters, asset needs, and review checklist. Mark uncertain font identities, audio judgments and approximate timings. Retain the prior styles. Do not embed someone else's reference footage in a user's deliverable.
