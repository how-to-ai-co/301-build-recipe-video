Nothing ships here; this folder fills up during setup.

Voiceovers: record one (a phone voice memo is fine) or generate with
ElevenLabs (parts/10), drop the file here, then run scripts/timings.py on it
to produce public/words/<NNN>.json.

Music: compose an original bed with `python3 scripts/bed.py` (writes
bed_phrygian.wav here; edit the CHORDS table for a different mood). Original
composition, so no licensing exposure. A config with no `bed` renders with no
music, which is a fine first pass.
