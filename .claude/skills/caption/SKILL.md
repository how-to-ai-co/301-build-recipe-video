# Caption

The default voice comes from one creator's captions (How to AI, 2026-10-13). Replace it with your own once you approve a few: all lowercase, super chill, "is it just me?" — like that.

## Rules

- All lowercase. No capitals anywhere, including "i", names and the first word.
- Super chill. It reads like a thought typed with one thumb, not marketing copy.
- Short. One line, a handful of words. The reference is `is it just me?`
- Do not summarise or restate the video's script. The video does the talking; the caption is an offhand reaction to it.
- No hashtags, emoji, or call to action unless the user asks for them.

## How to use it

1. Read the video's transcript so the caption fits what is said.
2. Offer two or three options in this style, each on its own line.
3. The user picks or rewrites. Never publish a caption they have not confirmed.
4. TikTok requires a title as well; use the same line.
